Memorial do Timão - Projeto Web 100% HTML 

Resumo do Projeto
Este projeto é um portal web académico interativo sobre a história, conquistas e ídolos do Sport Club Corinthians Paulista. O grande diferencial deste trabalho é ter sido desenvolvido **100% em HTML puro**, sem a utilização de CSS ou JavaScript. 

O foco principal foi cumprir rigorosamente uma extensa lista de requisitos técnicos, aplicando marcações semânticas, formulários avançados, elementos multimédia e interatividade nativa do HTML.

 Estrutura de Ficheiros
O projeto é composto por 12 páginas interligadas de forma fluida:

 `boas_vindas.html` - Página de entrada com simulação de acesso.
 `historia.html` - Fundação do clube e hino oficial.
 `titulos.html` - Galeria de conquistas (com tags avançadas de estatísticas).
 `idolos.html` - Os maiores nomes que vestiram a camisola.
 `fatosmarcantes.html` - Momentos históricos do clube.
 `jogoshistoricos.html` - Partidas inesquecíveis (com integração de vídeo e iframe).
 `artilharia.html` - Tabelas de maiores goleadores.
 `elenco2025.html` - O plantel masculino atual.
 `elencofemino.html` - As Brabas e os títulos recentes.
 `curiosidades.html` - Fatos interativos com efeito expansível.
 `sejasocio.html` - Formulário avançado para o programa Fiel Torcedor.
 `sardinha.html` - Página especial (homenagem/rivalidade desportiva).

 Requisitos Técnicos Implementados
Todas as exigências foram cumpridas utilizando exclusivamente recursos nativos do HTML5:

- Tags Semânticas:Estruturação completa de todas as páginas utilizando `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>` e `<address>`.
- Organização de Layout: Uso intensivo de tabelas (`<table>`, `<tr>`, `<th>`, `<td>`) sem bordas para alinhar e estruturar o conteúdo de forma responsiva nativa.
- Formulários Avançados: Implementação de formulário completo em `sejasocio.html` utilizando `<fieldset>`, `<legend>`, `<datalist>`, `<select>` (ComboBox), `<radio>`, `<checkbox>`, `<textarea>`, e inputs modernos (`date`, `file`, `range`, `color`, `required`, `placeholder`).
- Multimédia: Integração de áudio (`<audio>` com controls), vídeo local (`<video>`), vídeos externos (`<iframe>`), e imagens organizadas com `<figure>` e `<figcaption>`.
- Interatividade: Uso de `<details>` e `<summary>` para criar secções de conteúdo expansíveis sem JavaScript (FAQ e curiosidades).
- Marcação Avançada de Texto: Implementação cirúrgica de tags como `<mark>`, `<del>`, `<ins>`, `<progress>`, `<meter>`, `<abbr>`, `<cite>`, `<blockquote>`, `<q>`, `<big>`, `<small>`, `<em>`, `<sub>`, `<sup>`, e listas ordenadas/não ordenadas (`<ol>`, `<ul>`).

 Como Executar
Sendo um projeto em HTML estático, não é necessária a instalação de nenhum servidor.
1. Extrai ou clona a pasta do projeto.
2. Abre o ficheiro `boas_vindas.html` em qualquer navegador web (Google Chrome, Firefox, Edge, Safari).
3. Utiliza o menu de navegação presente em todas as páginas para explorar o conteúdo.
